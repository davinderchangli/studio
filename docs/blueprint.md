# **App Name**: Kitaba Di Dunia

## Core Features:

- Book Listing & Display: Display books with detailed information like title, author, and book sizes.
- Search and Filtering: Enable users to search for books based on title, author, or keywords. Filter books by size and category.
- Horizontal Navigation Bar: Implement a horizontal navigation bar for categories to easily browse books.
- Shopping Cart: Allow users to add books to a shopping cart for purchase.
- Checkout Process: Facilitate book purchasing by integrating with Stripe.
- User Account Management: Secure password reset functionality.
- Admin Panel: Admin access panel for managing books, categories, and user accounts. Protected via secure password.

## Style Guidelines:

- Primary color: Deep Indigo (#3F51B5) evoking the rich cultural heritage of Urdu literature.
- Background color: Light Gray (#EEEEEE), providing a neutral backdrop to enhance readability.
- Body font: 'Literata', a serif with a literary feel, best suited for larger text bodies.
- Headline font: 'Space Grotesk', a sans-serif to be used with Literata to make a stylish header.
- Simple, consistent icons for navigation and actions (e.g., cart, search, user profile).
- Clean, grid-based layout with ample white space to improve readability and focus on the content.
- Subtle animations for transitions and interactions, enhancing user experience without being distracting.
